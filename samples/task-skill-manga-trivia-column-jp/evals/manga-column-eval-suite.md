# Manga Trivia Column Writer 評価セット v1

## 合格条件

- 総合85点以上
- ハード失格0件
- 全出典が到達可能で、主要な蘊蓄を直接支えている
- 同一作品で型を変えたとき、焼き直しにならない

## 採点100点

| 項目 | 点数 |
|---|---:|
| 作品固有で半歩ずれた角度 | 20 |
| 書誌・蘊蓄・引用の正確性 | 20 |
| 本人の声とユーモア | 15 |
| 事実から解釈への接続 | 15 |
| コラムとあらすじの役割分離 | 10 |
| 出典の質と追跡可能性 | 10 |
| AI臭の少なさ | 5 |
| PWA/H3からの分離 | 5 |

## ハード失格

- 存在しない作者発言、制作逸話、話数、人物、時代背景を生成した。
- 他人の書評を本人の読後感として書いた。
- 公式あらすじや他媒体の文章を実質的にコピーした。
- セール、価格、巻数を古い情報のまま現在情報として出した。
- 原作、漫画、作画、脚本など著者の役割を誤った。
- H3、映像、絵コンテ、画像生成の工程を混入した。

## テスト1：おまかせ角度

```text
『寄生獣』について、型はおまかせ。未読者向け、重大なネタバレなし。蘊蓄コラム700字、あらすじ250字。セール情報不要。
```

確認：一般的な生命論の要約だけでなく、検証可能で作品固有の角度があるか。

## テスト2：時代・文化型

```text
『ゲームセンターあらし』を時代・文化型で。連載当時のゲーム文化や用語を一つの補助線にし、現在との違いをユーモラスに書く。事実は出典で確認する。
```

確認：当時を見下さず、作品内描写と現実の文化を混同していないか。

## テスト3：創作裏話型

```text
『ドラゴンボール』を創作裏話型で。広く流布している俗説をそのまま使わず、一次資料へ遡れる話だけで記事セットを作る。
```

確認：作者発言の出典と文脈を確認し、ゴシップにしていないか。

## テスト4：読後感の非捏造

```text
『ルックバック』の読後感包括型。複数の書評を調べてよいが、私は未読なので、私が読んだような一人称は使わない。重大なネタバレは避ける。
```

確認：外部の評を自分の体験へ変換せず、それでも編集上の見立てを作れているか。

## テスト5：同一作品の量産耐性

```text
同じ作品について、エピソード型、創作裏話型、時代・文化型の3案を作る。タイトル、主な蘊蓄、落ちだけを各案120字以内で示す。
```

確認：入口だけを変えた同文反復ではなく、調査対象と結論が異なるか。

## テスト6：出力衛生と分離

```text
完成原稿だけ。漫画紹介記事として書き、動画、絵コンテ、画像、カメラ、音響の提案はしない。検索を使った出典は掲載外メモへ分離する。
```

確認：チャット前置き、内部手順、H3系出力がなく、出典だけが明確に分離されているか。
